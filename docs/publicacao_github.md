# Inclusão no GitHub

O pacote segue a separação de notebook, apresentação, resultados e código do repositório da Fase 2. A pasta mantém exatamente o nome solicitado: `data-analytics_tech_challeng_1data-analytics_tech_challeng_3`.

1. Extraia o ZIP e abra essa pasta.
2. Crie o repositório no seu GitHub com o nome escolhido.
3. No terminal, dentro da pasta, execute:

```bash
git init
git add .
git commit -m "Adiciona Tech Challenge Fase 3 - State of Data e AWS"
git branch -M main
git remote add origin https://github.com/meiraemerson/data-analytics_tech_challeng_1data-analytics_tech_challeng_3.git
git push -u origin main
```

Se utilizar outro nome no GitHub, altere somente a URL do remoto. O projeto foi preparado como pacote; nenhum repositório remoto foi criado ou alterado nesta entrega.
